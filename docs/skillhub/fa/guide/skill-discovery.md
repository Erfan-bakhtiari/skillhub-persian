# جست‌وجو و نصب

## پیدا کردن مهارت یا مجموعه

از صفحهٔ اصلی یا جست‌وجوی رابط، واژهٔ مورد نظر را وارد کنید. در فهرست منابع، نوع «مهارت» یا «مجموعه»، فضای نام و برچسب‌ها را متناسب با گزینه‌های صفحه انتخاب کنید. مرتب‌سازی بر اساس ارتباط، تازگی یا تعداد نصب به نوع منبع و صفحه بستگی دارد.

کارت نتیجه را باز کنید و عنوان، نسخه، فایل‌ها و توضیح‌ها را ببینید. یک مهارت و یک مجموعه می‌توانند در فضای نام یکسان، slug یکسان داشته باشند؛ نوع منبع مشخص می‌کند کدام را باز کرده‌اید.

## نوشتار فارسی در جست‌وجو

در نسخهٔ دارای نرمال‌سازی فارسی، پرس‌وجو و نمایه از قواعد یکسان استفاده می‌کنند:

| نوشتارها | رفتار |
| --- | --- |
| «کیفیت» و «كيفيت» | یکسان |
| «کیفیت» و «كِيـفيت» | اعراب و کشیده نادیده گرفته می‌شوند |
| «برنامه‌نویسی» و «برنامه نویسی» | نیم‌فاصله معادل فاصله است |
| «برنامهنویسی» و «برنامه نویسی» | دو نوشتار مستقل‌اند |
| عدد فارسی و عدد لاتین | خودکار به یکدیگر تبدیل نمی‌شوند |

جست‌وجو ریشه‌یابی یا اصلاح خودکار غلط املایی انجام نمی‌دهد. می‌توانید فارسی و لاتین را در یک پرس‌وجو ترکیب کنید؛ مثلاً «کیفیت OpenAI». متن اصلی عنوان و توضیح در نتیجه حفظ می‌شود.

این قابلیت به استقرار کد و مهاجرت جست‌وجو وابسته است. اگر سرور قدیمی باشد، انتخاب زبان فارسی به‌تنهایی الگوریتم جست‌وجوی آن را تغییر نمی‌دهد.

## مشاهده و نصب

۱. نسخهٔ مورد نیاز و وضعیت آن را بررسی کنید.

۲. محتوای بسته و گزارش اسکن را بخوانید.

۳. فرمان نصب همان صفحه را کپی کنید یا از CLI استفاده کنید:

```bash
skillhub search pdf
skillhub install pdf-parser --agent codex
skillhub install @my-team/pdf-parser --version 1.2.0 --agent codex
```

slug بدون فضای نام به طور پیش‌فرض در `global` تفسیر می‌شود. در صورت استفادهٔ هم‌زمان از مختصات صریح و `--namespace`، هر دو باید یک فضای نام را مشخص کنند.

## دسترسی و نتایج خالی

جست‌وجوی عمومی فقط منابع قابل نمایش را برمی‌گرداند. مهارت `NAMESPACE_ONLY` به عضویت همان فضای نام وابسته است؛ `PRIVATE` در نتایج عمومی نمایش داده نمی‌شود. منابع پنهان یا بایگانی‌شده و نسخهٔ غیرقابل نصب ممکن است از نتایج حذف شوند.

اگر چیزی پیدا نشد، املای عبارت، نوع منبع، فضای نام، برچسب‌ها و وضعیت ورود را بررسی کنید. برای محتوای خصوصی خودتان از بخش مهارت‌های من یا مدیریت فضای نام استفاده کنید. [پرسش‌های متداول](../faq) علت‌های دیگر را توضیح می‌دهد.
