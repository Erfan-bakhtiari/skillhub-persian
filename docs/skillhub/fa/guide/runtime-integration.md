# قرارداد محیط اجرا

SkillHub و محیط اجرای عامل، مرجع داده‌های متفاوتی‌اند. مخزن مسئول بسته، نسخه، فراداده، snapshot اظهارنامهٔ انطباق، دانلود و سابقهٔ بررسی است. محیط اجرا مسئول ورودی و خروجی واقعی، فراخوانی مدل و ابزار و رد اجراست.

## اطلاعاتی که محیط اجرا ثبت می‌کند

| فیلد | منبع و کاربرد |
| --- | --- |
| `registryUrl` | نشانی مخزن در تنظیمات محیط اجرا |
| `namespace` | فضای نام مهارت |
| `skillSlug` | شناسهٔ مهارت |
| `requestedVersion` | نسخه یا انتخابگر درخواستی کاربر |
| `resolvedVersion` | نسخهٔ دقیق حل‌شده |
| `skillVersionId` | شناسهٔ نسخه از پاسخ مخزن؛ کلید اصلی اتصال سابقه |
| `complianceSnapshotDigest` | مقدار `complianceSnapshot.digest` |
| `packageDigest` | digest محتوای دانلودشده در مسیر نصب |
| `runtimeTraceId` | شناسهٔ رد ساخته‌شده توسط محیط اجرا |

اگر محیط اجرا فیلدهای `x-astron-*` دارد، نگاشت این داده‌ها بر عهدهٔ همان محیط است. سرور SkillHub رد فراخوانی مدل را ذخیره نمی‌کند و از روی اظهارنامه دربارهٔ انطباق اجرای واقعی تصمیم نمی‌گیرد.

## دریافت snapshot نسخه

از endpoint فعلی جزئیات نسخه استفاده کنید:

```http
GET /api/v1/skills/{namespace}/{slug}/versions/{version}
```

نمونهٔ فیلدهای مرتبط در دادهٔ پاسخ:

```json
{
  "id": 123,
  "version": "1.2.0",
  "complianceSnapshot": {
    "schemaVersion": "1.0",
    "digest": "sha256:8d8c...",
    "items": [
      {
        "standard": "mitre-attack",
        "version": "v19.1",
        "controlId": "T1059",
        "title": "Command and Scripting Interpreter",
        "evidence": [
          {
            "type": "packaged-file",
            "path": "references/mitre-t1059.md",
            "sha256": "sha256:..."
          }
        ]
      }
    ]
  }
}
```

هم `id` و هم digest را ثبت کنید. digest به‌تنهایی برای پیدا کردن نسخه در چند مخزن یا پس از مهاجرت کافی نیست. نمونهٔ بالا بخش داده را نشان می‌دهد؛ قرارداد کامل envelope و احراز هویت را از OpenAPI همان سرور بگیرید.

## ترتیب اجرای پیشنهادی

۱. مختصات و نسخه را حل کنید.

۲. جزئیات نسخهٔ دقیق و snapshot را بگیرید.

۳. بسته را دانلود و محتوای آن را مطابق قرارداد نصب راستی‌آزمایی کنید.

۴. مهارت را در محیط اجرا کنید.

۵. شناسهٔ نسخه، digest و شواهد واقعی اجرا را در رد خودتان ثبت کنید.

slug به‌تنهایی نسخهٔ تغییرناپذیر را مشخص نمی‌کند. snapshot بسته را به عنوان ادعای نویسنده بخوانید، نه گواهی مستقل. متن اصلی اظهارنامه و نام فیلدهای آن را برای فارسی‌سازی تغییر ندهید.
