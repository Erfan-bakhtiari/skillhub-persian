# آشنایی با SkillHub

SkillHub مخزنی قابل میزبانی در سازمان برای مهارت‌های عامل هوشمند است. هر مهارت یک بسته با فایل `SKILL.md` و فایل‌های مورد نیاز آن است. اعضای تیم بسته را منتشر می‌کنند و دیگران آن را با نسخهٔ مشخص پیدا و نصب می‌کنند.

## اجزای اصلی

| مفهوم | کاربرد |
| --- | --- |
| مهارت | دستورها، اسکریپت‌ها و منابعی که یک قابلیت را تعریف می‌کنند |
| نسخه | انتشار مشخص یک مهارت، مانند `1.2.0` |
| فضای نام | محدودهٔ نام‌گذاری و همکاری تیم، مانند `my-team` |
| مجموعه | ترکیب نسخه‌های مشخص چند مهارت با یک مهارت ورودی |
| بررسی | تصمیم مجاز دربارهٔ پذیرش یا رد نسخهٔ ارسالی |

نشانی استاندارد مهارت به شکل `@my-team/my-skill` است. عنوان نمایشی می‌تواند فارسی باشد؛ شناسهٔ فضای نام و مهارت باید قواعد فنی خود را رعایت کند. ترجمهٔ رابط، شناسه یا فایل‌های بسته را ترجمه نمی‌کند.

## مسیر استفاده

۱. وارد سامانه شوید و [مهارت‌های موجود را جست‌وجو کنید](./guide/skill-discovery).

۲. نسخه، فایل‌ها، توضیح‌ها و یافته‌های امنیتی را ببینید؛ سپس فرمان نصب را کپی کنید.

۳. برای اشتراک قابلیت خود، عضو فضای نام مناسب شوید و [بسته را منتشر کنید](./guide/skill-publish).

۴. [وضعیت بررسی](./guide/review) و [اعلان‌ها](./guide/social) را پیگیری کنید.

## معماری و مرز مسئولیت

رابط وب با React، API با Java و Spring Boot، پایگاه داده با PostgreSQL و نشست‌ها با Redis پیاده شده‌اند. فایل‌ها بسته به تنظیمات در ذخیره‌ساز محلی یا S3/MinIO قرار می‌گیرند. Docker Compose و الگوهای Kubernetes برای راه‌اندازی موجودند.

SkillHub بسته‌ها را مدیریت و توزیع می‌کند. اجرای واقعی مهارت، ورودی و خروجی مدل و ثبت رد اجرای ابزارها بر عهدهٔ محیط اجرای عامل است. برای اتصال سوابق به نسخهٔ بسته، [قرارداد محیط اجرا](./guide/runtime-integration) را بخوانید.

## نسخهٔ فارسی

از فهرست زبان رابط، «فارسی» را انتخاب کنید. چیدمان راست‌به‌چپ می‌شود و تاریخ‌ها و اعداد نمایشی با قالب فارسی نمایش داده می‌شوند. فرمان، نسخه، URL و کد همچنان چپ‌به‌راست‌اند. ترجیح زبان راهنما و برنامه مستقل است؛ در هرکدام زبان را جداگانه انتخاب کنید.

این راهنما رفتار سورس فعلی را شرح می‌دهد. قابلیت‌هایی مانند نرمال‌سازی فارسی جست‌وجو به استقرار همین نسخه و اجرای مهاجرت‌ها وابسته‌اند؛ وجود راهنما، نسخهٔ نصب‌شدهٔ سرور شما را تغییر نمی‌دهد.
